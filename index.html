An easier way to navigate the web
A GENTLER KIND OF PROGRESS
— ❧ —

A reusable React toolkit that gives forms adjustable pointer stabilization, forgiving target selection, and selection without a mouse button press.

Stabilization

Filter the browser's pointer coordinates, with a visible tradeoff between steadiness and responsiveness.

Target assistance

Make a nearby control easier to acquire, maintain a stable candidate through small movements, and decline ambiguous choices.

Activation

Route an explicit click or completed dwell to exactly the registered control the interface indicates.

Developer integration

Reuse the same engine across different forms while preserving their state, validation, and keyboard interaction.
